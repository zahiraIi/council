Before writing, ALWAYS re-read: the product blueprint, avatar profile, desires, mechanism, and the chosen angle. Do fresh research too: Reddit, TikTok, forums, and winning ads. "Input before output" [d:script-writing-guide]. Apply foundations/house-rules.md.

# Video ad strategy pipeline [n:ball img25-31]
1. Prep: competitor, sub-avatar, problem, and solution research → desires and candidate angles.
2. Core idea:
   - Choose a format (B-roll + VO, raw UGC…) and one core desire/angle.
   - NAME it and log it with a thesis for why it'll work.
   - First time out, use competitor winners for inspiration.
3. Framework = structure + tone + pacing ("an essay with a vibe").
   - Base structure: Hook → Bridge → Problem → Intro → Solution → Resolution → CTA.
   - Example: Hook → Problem → Exaggerate problem → Introduce product → Features → Failed solutions → Testimonial → CTA, with suspense music, slow pacing, captions, and overlays.
   - Hook matches the awareness level. The script is conversational and stays on ONE core idea.
   - Write the B-roll for each section.
4. Production:
   - Voiceover in ElevenLabs or via a creator brief.
   - B-roll from AI UGC, ripped content, or creators; it must match the sub-avatar.

# Mode A: clone a deconstructed winner [d:script-modelling-prompt]
1. Match the structure:
   - Every section, same order, ~same timing: opening stance, problem escalation, product entry, mechanism reveal, proof position, how transformation is shown, CTA style, objection positions, pacing.
   - Do NOT add, reorder, or introduce new concepts. "If the winning ad spends 30 seconds building the problem… your script spends 30 seconds."
   - Only swap product, avatar, mechanism, failed solutions, and social proof.
2. Use provided content only. No angles the files don't support.
3. Write 3 hooks of the same type and psychological function as the original.
4. Match runtime to the original (50s → ~50–60s).

# Mode B: from scratch, 7-part structure [d:script-writing-guide]
1. Hook: mirror a daily moment, qualify the avatar in 1–2s, open a loop.
2. Mirror & agitate: "this is literally my life".
3. Failed solutions, each causing a new problem (domino effect).
4. Root-cause education: the "aha", simple, technical terms explained.
5. Discovery story: organic (scrolling TikTok, saw the comments); social proof goes here.
6. Product as solution: solves the full root cause; every feature ties to the mechanism.
7. Transformation + soft CTA that echoes the hook moment.

Notes:
- The structure is an example; other structures are fine if they pass script-standards.md.
- Copy formula Adil uses on his own brand: pain points, promises, proof, constraints, curiosity [c:09-07].
- Length: 45–70s for B-roll + VO [c:07-06, c:08-06].

# Process
- Clear your head (morning or 10 min meditation). Draft fast like an essay, then revise [d:script-writing-guide].
- Run the self-check in script-standards.md before delivering. Revise any ❌.
- Deliver HOOK 1/2/3 + SCRIPT BODY. When the user is drafting interactively, go line by line and ask for approval after each line [d:script-modelling-prompt].
- Package it in the script brief (script-brief.md) with 3 variations, then log it to products/<p>/creatives.yaml.
- Batch = 3 ads; one format per angle with 3 strong variations [c:06-25, c:07-23].
