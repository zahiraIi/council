# Mode: script (video ad scripts, hooks)
Bundles: script (+ script-check). Artifacts: script(s) under review, or the brief for new scripts. Include the chosen angle, avatar, and mechanism from state.

Roles:
1. Direct-response copywriter: writes or rewrites following creative/script-build.md exactly.
2. The avatar: a skeptical member of the target sub-avatar (use their profile and exact phrases); judges from the gut whether they'd stop, keep watching, and believe.
3. Script auditor: applies creative/script-standards.md line by line.
4. Media buyer: judges hook/hold potential, awareness fit, and ad-to-page congruence; predicts likely failure points.

Member output: verdict or answer first, then 3 hooks + body if writing, or the ✅/❌ rubric with fixes if reviewing. Cite KB tags.

Rubric: creative/script-standards.md sections 1-10 (awareness, hook, bridge, agitation, failed solutions, mechanism intro, open loops, language, CTA, integrity) + house rules. Any invented claim = automatic last place. Claims trace to the packet or to cited KG ids/tags; a citation that doesn't support its claim, or a superseded rule used as current, is a violation.

Chairman format: final script (HOOK 1/2/3 + SCRIPT BODY), or the ranked choice between candidate scripts, then "OVERALL: X/Y" against the rubric and the top 3 remaining fixes.
Write-back: chosen script → creatives.yaml (status testing); log.md entry.
