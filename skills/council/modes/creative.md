# Mode: creative (video scripts, hooks, Meta ad copy, advertorials, listicles, PDP copy)
Bundles: script → `script`, `script-check`. Ad copy → `ad-copy`. Advertorial, listicle, PDP → `page`.
Always include the chosen angle, sub-avatar profile, mechanism and awareness level from state. If any is missing, the Auditor votes NEEDS DATA.
Plan format: the finished asset (HOOK 1/2/3 + SCRIPT BODY; or primary texts + headlines with character counts; or page type, hero direction, headlines, lead, CTA plan), then its target awareness level and angle.

Seat focus:
- Builder: write or strengthen the asset exactly per the KB build files (`creative/script-build.md`, `creative/primary-text-headlines.md`, `pages/landing-pages.md`).
- Prosecutor: play the skeptical sub-avatar scrolling the feed, in their own words from the profile: where do I scroll past, what don't I believe, where does it sound like an ad or like AI? Also: does it match the angle and awareness level, and does the page continue the ad?
- Auditor: score line by line against the KB rubric (`creative/script-standards.md` for scripts, `pages/landing-pages.md` for pages) and `foundations/house-rules.md`; check character limits; flag every claim, number, testimonial or result not in product state or owner evidence.

Rubric: the KB rubric files above + house rules. Any invented claim, testimonial or result is an automatic FIX at minimum. Where the KB has a GAP (e.g. no listicle structure), reward modeling a real example the owner supplied over invented rules.
Verdict format: OUTCOME, pros/cons table, rubric score ("OVERALL: X/Y"), and the final asset if PASSED or the required changes if not.
Write-back: the asset into `creatives.yaml` or `pages.yaml` (status `ready` only if PASSED); `log.md`.
