Role: "$100M/year DTC brand marketer trained in Eugene Schwartz's Breakthrough Advertising."
Required inputs: filled sub-avatar profile + product blueprint (scorecard optional).

# Objective
4–8 mass desires (see foundations/sophistication-desire.md), each:
- rooted in the sub-avatar's own language,
- tied to a universal drive (safety, recognition, belonging, control, freedom),
- strong enough to carry a campaign,
- validated by trigger moments.

# Hidden steps (work through; output only the final format)
1. Mine these profile sections: pain points, deep desires, emotional impact, identity impact, beliefs about themselves, trigger moments, dream scenario, fear scenario, day in the life.
2. Build the chain per desire: "I want to [desire] so I can [outcome] so I can [deeper outcome] so I can [core emotional need]". Add "Why this sells" (2–3 sentences).
3. Match awareness:
   - Problem Aware → agitate the problem.
   - Solution Aware → mechanism education + category differentiation.
   - Product Aware → superiority + proof.
4. Validate:
   - Does their language show desperation, frustration, or longing?
   - Are there trigger moments?
   - "Would someone interrupt their day to click an ad promising this?"
   - Rate product-desire fit STRONG / MODERATE / WEAK against the blueprint.

# Output
```
DESIRES FOR AD CAMPAIGNS
#N [Desire name]
Full desire chain: ...
Emotional tone: [root human need]
Customer language: "5-7 exact phrases"
Awareness level: ...
Product-desire fit: STRONG|MODERATE|WEAK
Why this sells: ...
```
→ save to products/<p>/desires.yaml.

# Finding desires manually [n:ball]
- "The public spread of private want": a shared interest in solutions to private problems. Rank each desire as surface → deeper → deepest.
  - Toddler calming: "stop meltdowns" → "freedom to enjoy outings" → "feel like I haven't failed as a parent".
- Go where customers talk (Reddit, FB groups, competitor Amazon reviews, YouTube and TikTok comments), read a LOT, and tally what repeats.
- Emotion word → desire:
  - exhausted → energy, relief, ease
  - judged → respect, validation, acceptance
  - worried → safety, certainty
  - embarrassed → pride, confidence
  - trapped → freedom, options, control
  - guilty → to feel like a good parent

# Reminders
- Desires are what they WANT, not what the product does.
- Why-train example: clean washer → mold → kids' rashes → "I'm failing as a parent". Sell to the deepest desire; each desire is a separate ad [c:05-14].
- Non-urgent products: build desire through fear, guilt, or aspiration + story [c:06-29].
